# Riot Stars PT-BR — alpha12 experimental

[Baixar pacote completo](Riot-Stars-PTBR-patch-alpha12.zip?raw=true)

[Patch BPS separado](Riot-Stars-PTBR-alpha12.bps?raw=true) · [CSV do roteiro principal](roteiro-principal-alpha12.csv?raw=true) · [Changelog](CHANGELOG.md)

Aplique apenas ao BIN japonês original. Não aplique sobre uma tradução anterior.
SHA256 do original: `18a138b66ee070ce96a0c6aa559176a4631780e5c52d415289aaef99e2b8479f`.

O pacote inclui aplicador Python, módulo BPS e CUE. Para uso, execute `python aplicar_patch.py --help`. Os dois arquivos Python devem ficar juntos.

O CSV cobre o roteiro principal, com japonês, português, posição e estado de inserção; não representa todo o texto gráfico e audiovisual.

64 testes locais passaram; patch reaplicado com igualdade byte a byte e setores modificados verificados. Menu, teclado, abertura e primeira batalha examinados em PCSX-ReARMed HLE. Ainda falta partida completa e validação das rotas, saves e vídeos no DuckStation. Não há percentual global confiável.

Esta publicação contém patch, ferramentas e documentos; não contém a imagem do jogo.
